## 1. 개요
- 시설 관리자가 되어, 야간 동안 패널의 장치들을 조작해 설비가 정상 작동하도록 유지하는 게임.
- 플레이어는 '관리실' 공간 내에서 버튼 및 기타 조작 장치를 조작하여 설비 A, B, C의 고장 상황을 해결하며 게임을 진행하고, 진행 상태가 100%가 되면 승리하고, 내구도(체력)가 전부 감소하면 패배한다.
- 시점 : 1인칭
- 한 판 플레이 시간 : 약 5분
- 승리 : 진행도 100% / 패배 : 내구도 0

## 2. 핵심 경험
- 플레이어는 **시간 내에, 올바른 조작**을 하여 게임을 진행하는 경험을 하며 게임을 클리어 한다.
- 설비가 정상이면 안정, 고장 나면 불안정. 제때 고치면 다시 안정으로 돌아오고, 못 고치면 내구도가 깎인다. 이 대비를 표시, 빛, 사운드로 체감하는 것이 경험의 중심이다.
- 판단은 단순하게 : 매뉴얼에 적힌 대로 조작하면 된다. 복잡한 퍼즐은 없다.
- 긴장은 시간에서 : 정해진 시간 안에 정확하게 조작해야 하기 때문에 시간에 쫓긴다.
	- 압박이 너무 약하면 무의미한 버튼 조작이 되고, 너무 강하면 짜증나는 도전이 된다.

## 3. 핵심 메카닉
- 고장 : 설비가 고장 나면 진행도가 멈추고 제한 시간이 흐른다. 시간 안에 고치지 못하면 내구도가 깎인다.
- 조작 : 공간 속 장치(Diegetic UI)인 버튼, 슬라이더 등을 직접 조작한다. 진짜 시스템 패널을 관리하는 관리자가 된 듯한 경험을 준다.
- 매뉴얼 : 각 고장에 대한 대응법을 적은 설명서이다. 퍼즐의 답지가 아니다.
	- 예) A 요소가 고장 났을 시 4x4 버튼을 화면에 띄워진 형태로 누르시오.
	- 튜토리얼 역할을 겸하며, 나폴리탄 괴담 스타일로 게임의 설정과 세계관을 전달한다.
- 설비
	- A : 4x4 버튼을 화면에 띄워진 형태대로 누른다.
	- B : 소리로 슬라이더의 상태를 확인하며, 4개의 슬라이더를 목표 위치로 옮긴다.
	- C : [미정]
- 동시 고장 : 여러 설비가 동시에 고장 날 수 있다. 처리 순서는 자유이며, 시간 내에 모두 처리하는 것이 목표다.

## 4. 플레이 루프
| 단계 | 플레이어 행동 | 피드백 |
| --- | --- | --- |
| 고장 인지 | 전면 메인 패널에서 고장 난 설비를 확인한다 | 사이렌, 전면 패널의 붉은 불, 전면 패널의 디지털 타이머 시작 |
| 매뉴얼 확인 | 후면으로 돌아 매뉴얼을 읽는다 (숙련자는 생략) | - |
| 조작 | 해당 설비의 조작부로 이동해 장치를 조작한다 | 버튼 On/Off, 슬라이더 위치와 소리 |
| 결과 | 성공 : 정상 상태로 복귀 / 실패 : 내구도 감소 | 성공음 + 전면 패널의 초록 불 / 내구도 게이지 감소 |

## 5. 상태별 경험
| 상태 | 조건 | 감정 | 표시 / 빛 | 사운드 |
| --- | --- | --- | --- | --- |
| 안정 | 모든 설비 정상 | 안도감, 성취감 | 전면 패널의 초록 불 | 정상화 시 성공음, 평소에는 웅웅거리는 기계 소리 |
| 불안정 | 설비 고장 | 위기감 | 전면 패널의 붉은 불 | 사이렌, 고장 난 듯한 기계 소리 |

- 고장 난 설비가 많을수록 사이렌이 커지고 붉은 표시의 면적이 넓어진다.
- 내구도가 낮으면 위급하고 불안정한 앰비언스를 더한다. (별도 상태로 나누지 않는다)
- 수리 성공은 시각(초록 불)과 사운드(성공음)로 이중 부호화한다. 측면에서 조작 중이어도 소리로 성공을 알 수 있다.

## 6. 한 판의 흐름
1. 시작 : 모든 설비 정상(초록), 내구도 가득, 진행도 0. 여유 시간에 매뉴얼을 읽는다.
2. 고장과 수리 : 고장 → 수리 → 안정 복귀를 반복하며 진행도를 채운다.
3. 위기 : 여러 설비가 동시에 고장 나거나 내구도, 제한 시간이 얼마 남지 않아 빠르게 조작해야 한다.
4. 결말 : 진행도 100%면 승리, 내구도 0이면 패배. 승리 / 패배 UI를 표시한다.
	- 승리 시 바닥의 문을 열고 탈출하는 컨셉이 있으나, 애니메이션 구현 부담으로 UI 표시로 대체한다.

## 7. 공간과 분위기
- 어두운 관리실이지만 초록 빛을 받는, 다소 안정된 분위기. 야간에 불 꺼진 시설을 지키는 관리자가 된 기분.
- 전면 메인 패널 : 모든 상태 표시를 한곳에 모은다.
	- 설비별 고장 / 정상 표시등, 디지털 시계 형식의 제한 시간 타이머
	- 플레이어는 측면의 장치를 조작하다가도 상태를 확인하려면 전면 패널을 봐야 한다.
- 매뉴얼(후면)과 조작부(전면, 좌우측면)의 분리는 의도된 불편함이다. 매뉴얼을 보면서 동시에 조작할 수 없다.
- 평소에는 전면 메인 패널을 주시하고, 고장이 나면 메인 패널과 조작부를 오간다.

## 8. 학습과 반복 플레이
- 초반의 안정된 시간에 매뉴얼을 읽으며 조작법을 익힌다. 복잡하지 않아 금방 익힐 수 있다.
- 반복 플레이 요소는 두지 않고, 한 판 자체의 완성도에 집중한다.
